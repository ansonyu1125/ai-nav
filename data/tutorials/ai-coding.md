AI 编程，就是让 AI 帮你写代码、改代码、找 bug。这两年它已经从一个「玩具」变成了真正能提升效率的工具——不夸张地说，学会用 AI 编程，你的开发效率能翻倍。这篇教程从工具选择到实战用法，讲透。

## 一、先搞懂：AI 编程到底帮你干嘛

记住一句话：**AI 不替你做决定，但它替你把「重复劳动」干了。** 具体能帮你：

- **代码补全**：写函数时自动预测下一行 → 省下打字时间
- **对话改代码**：「给这个函数加空值校验」→ 省下手动改的功夫
- **解释代码**：「这段代码在干嘛？」→ 省下读别人代码的时间
- **找 bug**：「为什么这里报错？」→ 省下排查的时间
- **写测试/注释**：「给这个类写单元测试」→ 省下枯燥的活

**但它不会替你负责**：AI 写的代码可能藏 bug，你要看懂、要测试。这是「人机协作」，不是「全自动」。

## 二、主流工具怎么选

- **Cursor**：基于 VS Code，体验最成熟——适合大多数开发者
- **GitHub Copilot**：补全为主，融入编辑器——适合老牌、求稳
- **Claude Code / Codex**：命令行 Agent，能自主多步干活——适合进阶、要自动化的
- **Windsurf**：类似 Cursor，各有特色——适合想试试别的
- **通义灵码 / 豆包 MarsCode**：国内免费、中文友好——适合国内用户

**新手建议**：直接上 **Cursor**，它免费额度够用，界面和 VS Code 一样，学习成本最低。国内用户如果 Cursor 用着卡，可以先用**豆包 MarsCode**或**通义灵码**，都是免费的。

## 三、上手 Cursor（三步）

1. 去 [cursor.com](https://cursor.com) 下载安装
2. 它会提示导入 VS Code 配置，直接导入（快捷键、主题、插件全保留）
3. 登录后就能用免费额度，先用起来，不够再考虑订阅

## 四、三个核心用法（按使用频率排）

### 1. 代码补全（无感但高频）

正常写代码，Cursor 会自动给灰色补全建议，按 `Tab` 接受。你写个函数名，它可能直接补全整个函数体。**养成「Tab 接受」的习惯**，打字会少很多。

### 2. 对话式改代码（最常用）

选中一段代码，按 `Ctrl+K`（Mac 是 `Cmd+K`），直接说人话：

> 给这个函数加上输入校验，处理空值的情况

它会生成修改后的代码，你对比 diff 后**接受或拒绝**。这就是「你负责提需求，它负责动手」。

### 3. 全局聊天（问问题）

按 `Ctrl+L` 打开聊天面板，可以：

- 选中代码 + 问「这段在干嘛」
- @ 引用某个文件，问「这个模块怎么改成异步的」
- 直接描述需求「帮我写一个导出 Excel 的功能」

## 五、真实场景演练：从 0 写一个小功能

假设你要写一个「判断身份证号是否合法」的函数，这样操作：

1. 打开聊天面板，输入：
   > 用 Python 写一个校验身份证号合法性的函数，要求：校验长度、出生日期合理性、最后一位校验码，并加上中文注释。

2. 它给出代码后，你再追问：
   > 给这个函数补几个测试用例，覆盖正常、长度错误、日期非法三种情况。

3. 最后让它解释：
   > 校验码那一段的逻辑讲一下，我看不懂。

三步下来，你不仅有了代码，还**真的看懂了**——这才是 AI 编程的正确姿势，而不是「复制粘贴跑起来就完事」。

## 六、进阶：让 AI 更懂你的项目

### 1. `.cursorrules` 文件

在项目根目录放一个 `.cursorrules` 文件，写清项目规范，AI 会一直遵守。比如：

```
这是一个 TypeScript 项目，请：
- 使用函数组件和 hooks，不要用 class 组件
- 命名用小驼峰
- 每个函数写清晰的中文注释
```

### 2. Agent 模式（自主多步）

Cursor 的 Agent 模式能自己读文件、改多处、跑命令，适合「把整个功能交给它」。但**务必小步审查**，别让它一次改太多你来不及看。

## 七、避坑指南（新手最容易踩）

- **别盲信 AI 代码**：它可能用了不存在的 API、过时的库，跑之前自己看一遍。
- **小步提交**：让 AI 一次只做一件事，方便你审查和回滚。
- **保持 review 习惯**：AI 写的代码，你必须能看懂、能测试，否则出了 bug 你没法修。
- **别把公司核心代码/密钥贴给它**：注意数据安全。
- **AI 会偷懒**：它可能写出「看起来对但有逻辑漏洞」的代码，边界条件要自己多想想。

## 八、哪些场景 AI 最靠谱 / 最不靠谱

**靠谱**：写工具函数、写测试、写注释、解释代码、重构命名、写模板代码。

**要谨慎**：复杂业务逻辑、多线程并发、性能优化、安全相关的代码——这些错了不容易发现，必须人工把关。

## 总结

- 新手直接上 **Cursor**（免费额度够用）
- 三个核心用法：**补全（Tab）、改代码（Ctrl+K）、问问题（Ctrl+L）**
- 正确姿势：**让 AI 写 + 追问解释 + 自己测试**，而不是复制粘贴
- 避坑：小步审查、看懂再跑、别贴敏感信息

一句话：**AI 编程是「你负责方向和审查，AI 负责重复劳动」，用好它，效率翻倍；用坏它，bug 翻倍。**
